Third-party software

The server and the web UI are built from open source libraries. Their licence
texts and copyright notices are part of the packages they come from; this is
an overview of what the container image and a build of this repository carry.

Server (Rust crates linked into the astrum binary; exact versions in
Cargo.lock; a full list comes from `cargo tree -p astrum-server -e normal
--format "{p} {l}"`):

  - MIT License, Apache License 2.0, or both: the large majority of the
    crates, among them tokio, axum, hyper, reqwest, rustls, sea-orm, sqlx,
    serde and tracing.
  - BSD-3-Clause: curve25519-dalek, ed25519-dalek, x25519-dalek, cx448,
    subtle, and matchit (with MIT).
  - ISC License: ring (with Apache-2.0), rustls-webpki, untrusted, sqlmig.
  - Zlib License: foldhash, zlib-rs. bzip2-1.0.6 licence: libbz2-rs-sys.
  - 0BSD, Unlicense or MIT: adler2, memchr, aho-corasick, byteorder.
  - Unicode License v3: the Unicode data crates (icu_*, unicode-ident, zerovec
    and the crates around them).
  - CDLA-Permissive-2.0: webpki-roots, the list of root certificates of the
    Mozilla CA Certificate Program.
  - Mozilla Public License 2.0: ldap3_proto, used unmodified. Its source code
    is available at https://github.com/kanidm/ldap3.

Web UI (npm packages bundled into web/dist; exact versions in
web/pnpm-lock.yaml; a full list comes from `pnpm licenses list --prod` in
web/):

  - MIT License: React, React DOM, React Router, TanStack Query, Radix UI and
    Radix Themes, Floating UI.
  - ISC License: lucide-react. Copyright (c) Lucide Icons and Contributors.
  - Apache License 2.0: Swagger UI (swagger-ui-dist), which shows the REST API
    on the API page; its bundle carries the licences of the libraries inside
    it in swagger-ui-es-bundle.js.LICENSE.txt. Its NOTICE reads:
      swagger-ui
      Copyright 2020-2021 SmartBear Software Inc.
  - 0BSD: tslib.
  - SIL Open Font License 1.1: the Geist and Geist Mono fonts served with the
    UI (@fontsource-variable/geist, @fontsource-variable/geist-mono).
    Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font).
    The licence is at https://openfontlicense.org/open-font-license-official-text/.
